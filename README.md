## 🚀 Selected Work

### 📝 AI Exam Grader (VLM-Powered)
An automated system for grading **handwritten theory exams**, built to reduce bias and inconsistency in manual marking.

- Visual Language Models interpret handwriting & diagrams
- LLM agents grade against official marking guides
- Async job processing + real-time progress updates
- Designed for scale and fairness in large exam systems

**Stack:** Next.js, FastAPI, LangGraph, PostgreSQL, Redis, RabbitMQ, Docker
